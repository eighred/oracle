# Portfolio report API

The local Vue workstation reads a versioned envelope containing the dated risk report and the full net-of-cost backtest. The publishing command uses the same Rust domain functions as the financial CLIs. PostgreSQL stores the exact serialized bytes. A check constraint binds their SHA-256 to the report ID. Repeated publication preserves the original row. A reader can request the latest publication or an immutable ID at `GET /api/portfolios/{portfolio}/reports/{version}`. The response supplies the digest in `x-oracle-report-id`.

The [migration](migrations/001_workstation.sql) defines separate writer and reader roles, expiring sessions, access grants and forced row-level security. Publishing uses `oracle-report-api publish-synthetic` with a writer connection. Serving uses `oracle-report-api serve WEB_DIST` with a reader connection. The API reads `ORACLE_DATABASE_URL` and binds to loopback on `ORACLE_PORT` (default 8040). The database connection supports a Unix socket or numeric loopback IP. This local pilot uses the browser's HTTP Basic prompt over loopback. The operator chooses a temporary passphrase at a masked prompt. PostgreSQL holds a 16-byte random salt and a PBKDF2-HMAC-SHA256 verifier with 600,000 iterations per principal. The browser checks use randomly generated temporary passphrases. Do not expose this development listener through a public reverse proxy.

Each GET checks the credential and portfolio grant in a read-only transaction on a shared connection. The session settings last for that transaction. Database policies also evaluate the grant at row access. The API verifies the digest before returning bytes and disables HTTP caching. Invalid or expired credentials yield 401, denied portfolio scope yields 403, and an authorized missing report yields 404. The reader has no table grants on session credentials or portfolio grants.

Use the [web runbook](../../../web/README.md) to launch the disposable integration or reproduce its verification. On a fresh pilot cluster, `pg_dump` and `pg_restore` into a second database preserve report bytes, session expiry and grants. Cluster roles are shared between the databases for this test. Recovery to a new estate would require restoring roles separately. A lost database connection requires restarting the local API. The synthetic fixture, loopback authentication and cluster restore establish development behavior only.

## Forward paper journal

The [paper migration](migrations/002_paper.sql) follows the workstation migration. PostgreSQL owns the frozen manifest, receipts, committed next instructions and simulated postings. A paper operator can read and append journal entries. The report writer can replay the journal and publish its terminal projection. The browser reader sees published bytes through the existing portfolio policy. Historical and paper reports have separate latest and immutable routes.

Use `oracle-report-api paper freeze FIRST_MS` before the first scheduled UTC minute. The nine-sample manifest fixes the instrument, price generator, three warm-up samples, six settlement opportunities, starting balances, rule set, cost model, acceptance, receipt deadline and source fingerprint of the pricing and decision engine. The operator invokes `paper sample FIRST_MS INDEX` once per minute, with zero-based indices. The synthetic source draws a new uniform price in whole cents between 23 and 27 USDT at receipt. Every journal entry atomically records that observation, the portfolio projection and any instruction for the next minute. Replay checks each posting against the instruction from the previous committed entry.

Resubmit the same index after an uncertain acknowledgment. A per-window transaction lock and unique event key serialize retries, cancellations and concurrent samplers. Late observation requests record a terminal missed slot. An operator can use `paper cancel FIRST_MS` to stop before the next settlement. Run `paper report FIRST_MS` to reconstruct the journal. Run `paper publish FIRST_MS` with a report writer to publish complete, missed or canceled results. The authorized endpoint is `GET /api/portfolios/{portfolio}/paper/{latest-or-id}`. The [independent verifier](../backtest/tests/paper_reference.py) accepts a complete exported experiment. It recomputes signals, all balances, individual costs, realized/unrealized P&L, turnover and drawdown with rational arithmetic.

The controlled source exercises decision timing and recovery with independently drawn prices. Exchange order-book liquidity, market returns, supplier rights and suitability for own capital require separate evidence.
