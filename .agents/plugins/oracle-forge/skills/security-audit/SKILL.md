# Security audit

Read the repository AGENTS.md and SECURITY.md. For a focused review, trace the requested principal, policy, resource, enforcement point and corrective change. For a broad review, inventory boundaries once, record coverage and inspect each selected source path. Use static evidence, normal regression tests with synthetic data and authorized configuration readbacks. Keep exploit construction, vulnerability reproduction and autonomous offensive testing outside this workflow.

Preserve the source revision, exact path and line, confidence, missing deployment evidence and owner. A clean reviewed path establishes only the examined scope. Use the offline report and coverage validators for compatible structured artifacts. A schema pass alone cannot prove a security property.
