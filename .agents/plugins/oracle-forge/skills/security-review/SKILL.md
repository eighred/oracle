# Review an Oracle control

Identify the principal, resource, enforcing component and durable decision record. Trace a permitted and denied case with synthetic data or read-only configuration evidence. Check who can change the policy and view the resulting logs. Redact sensitive evidence.

Distinguish rules tracked in the checkout, hosted rules read back from GitHub and controls observed on managed devices. CODEOWNERS identifies reviewers. Directory confidentiality requires independently permissioned storage and controlled developer access. Compare claims to SECURITY.md and state the missing external evidence. Source review supplies no authority to probe production.
